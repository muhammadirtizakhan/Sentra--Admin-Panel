## 🧭 About the Admin Panel

SENTRA Admin Panel is the company-facing control workspace for the SENTRA CCTV analysis platform. It gives authorized administrators a single place to review user access, process invitation requests, and monitor the recording library.

The admin panel is separate from the user dashboard. Company administrators sign in with dedicated admin credentials; ordinary SENTRA user accounts cannot sign in to this workspace.

## ✨ What administrators can do

| Area | Capabilities |
|---|---|
| 📈 **Overview** | Review account and recording totals, recent activity charts, processing states, and invitation status summaries. |
| ✉️ **Invitations** | Search and filter access requests, choose the devices for a user, and send an invitation code and instructions by email. |
| 👥 **Users** | Browse registered accounts, check account status and assigned devices, and review registration details. |
| 🎞️ **Recordings** | Search the recording library and inspect processing, video-upload, and detection-data states separately. |
| 🔒 **Admin access** | Use a dedicated company-admin sign-in and protected server-side routes to keep administration separate from user access. |

## 🏗️ How it fits into SENTRA

The admin panel complements the user-facing dashboard and the local Python video-analysis application. The Python application analyzes CCTV footage and syncs supported records to the shared cloud data layer. The user dashboard provides users with their events and recordings. The admin panel provides company administrators with access management and an operational view of users and recordings.
